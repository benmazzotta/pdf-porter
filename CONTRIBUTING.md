# Contributing

Thanks for your interest. pdf-porter is deliberately small: one tool, one job.

- **Open an issue before a pull request.** Unsolicited PRs may be closed without review.
- Bug reports need the pdf-porter version, your OS and a PDF (or a description of one) that shows the problem. Please use the issue form.
- Feature requests that add tools or configuration are likely out of scope. For the full Docling toolset, see [docling-mcp](https://pypi.org/project/docling-mcp/).
- Security problems: see [SECURITY.md](SECURITY.md). Do not file them as issues.

Issues or PRs that are spam, automated, or don't follow these notes may be closed without comment.
